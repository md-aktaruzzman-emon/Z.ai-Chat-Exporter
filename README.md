# Z.ai Chat Exporter v2.0.0

A complete, production-grade Chrome Extension (Manifest V3) designed to export chats from `https://chat.z.ai/*` into Selectable Vector PDF, Raster PDF, DOCX, Markdown (GitHub, Obsidian, Notion presets), HTML, TXT, JSON, PNG, and CSV.

## 🚀 Key Features

- **Local-Only & Zero External Network Requests:** All rendering, conversion, and parsing runs 100% locally in your browser. Zero telemetry, zero analytics, zero CDNs.
- **Selectable Vector PDF & Raster PDF:** Supports clean selectable vector PDF generation via `pdf-lib` and full page fidelity via `html2pdf.js`.
- **Three Markdown Presets:** GitHub-flavored markdown (GFM), Obsidian callouts/wikilinks, and Notion paste-safe Markdown.
- **Deep DOM Scraper:** Robust scraper handling dynamic SPAs, open Shadow DOMs, streaming assistant generation detection, and automatic un-virtualization.
- **Local PII Anonymizer:** Redacts emails, phone numbers, API keys, bearer tokens, and JWT credentials locally before export.
- **In-Browser IndexedDB History:** Optional local history cache with a 200-entry LRU eviction policy.
- **Multi-Language Support:** Fully localized in English (`en`) and Bengali (`bn`).

## 📦 Tech Stack & Architecture

- **Manifest V3:** Background Service Worker strictly performs message routing and download initiation (Rule R2: Service worker never touches DOM).
- **Offscreen Document:** All DOM manipulation, KaTeX math parsing, Prism code formatting, and canvas rendering occur inside Chrome's sandboxed offscreen document.
- **Closed Shadow DOM:** Floating Action Button (FAB), export panel, and modal overlays are injected into a closed Shadow DOM to avoid interfering with target page styling.

## ⚙️ Installation (Unpacked Extension)

1. Clone or download this repository.
2. Run `npm install` and `npm run build`.
3. Open Google Chrome and navigate to `chrome://extensions`.
4. Enable **Developer mode** toggle at the top-right.
5. Click **Load unpacked** and select the `dist/` directory generated by Vite.

## 🔒 Known Platform Limitations

1. **Cross-Origin Images:** In accordance with Chrome's MV3 security model and our strict Zero-External-Network policy, images hosted on cross-origin domains that do not permit CORS cannot be re-fetched into base64 data URIs. Same-origin images and inline data URIs are embedded directly.
2. **True Vector Math Fonts:** Web browsers do not bundle native MathML-to-Type1/TrueType math font embeddings in simple vector PDF generators. Mathematical expressions in vector PDFs are rendered with clean Unicode text approximations or rasterized equations.
3. **Canvas Height Limits:** Large conversation exports to PNG are safely split across sequential image slices to prevent exceeding browser canvas memory and dimension limits.
